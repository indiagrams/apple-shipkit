# Accepted exceptions for ci/check-push-secrets.sh.
#
# Format:  <object-sha | path:NAME>   # the reason, which is REQUIRED
#
# Adding a line here is a RULING: it records that someone looked at that object
# and decided publishing it is acceptable. Typical reasons are a credential that
# has been revoked and is already public elsewhere, or a configured value that
# is a documented placeholder rather than a secret.
#
# It is not a way to quiet the gate:
#   - every accepted object is PRINTED with its reason on every run, and counted
#     in the verdict line. An exception you stop seeing is one you stop
#     re-deciding.
#   - an entry with no reason after the '#' is a RED, not an acceptance. A bare
#     sha is indistinguishable from a mistake.
#   - accepting one object never silences a different one.
#
# The template ships this file empty. Forks add their own rulings below.
